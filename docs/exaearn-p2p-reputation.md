# ExaEarn P2P Reputation

Reputation is versioned through `P2PReputationService::VERSION`.

Current version:

`p2p-reputation-v1`

Inputs:

- Total orders.
- Completed orders.
- Completion rate.
- Dispute count.
- Dispute rate.
- Average counterparty rating.

Snapshots are stored in `p2p_reputation_snapshots` and merchant profile metrics are updated when available.
