# ExaEarn ExaSkills Security

Security controls include:

- authenticated course purchase, enrollment, media and progress writes
- server-side private media access checks
- instructor self-purchase prevention
- server-scored assessments
- idempotent paid purchases and payouts
- admin-only moderation, credential revocation and payout approval
- activity logging for course transitions and media access

Future live learn-to-earn rewards must add Phase 18 anti-abuse controls before enablement.
