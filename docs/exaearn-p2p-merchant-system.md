# ExaEarn P2P Merchant System

Phase 11 adds `p2p_merchant_profiles` for merchant state, tier and operating metrics.

## States

- `applied`
- `under_review`
- `approved`
- `active`
- `restricted`
- `suspended`
- `revoked`

## Tiers

- `standard`
- `verified`
- `pro`
- `institutional`

Merchant approval remains an operational/admin process. The software does not auto-approve merchants solely from balance size or trading volume.
