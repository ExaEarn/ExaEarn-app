# ExaEarn Phase 13 ExaAI Operations

## Admin Controls

- Configure market/product eligibility.
- Set global ExaAI control state.
- Review readiness.
- Review surveillance cases.

## Operational Modes

Public launch is not automatically enabled by code. Software readiness is separate from:

- compliance approval
- operations staffing
- strategy governance
- liquidity provisioning
- incident response

## Failure Policy

Uncertain state means no new risk. Existing manual trading remains separate.
