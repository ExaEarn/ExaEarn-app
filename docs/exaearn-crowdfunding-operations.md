# ExaEarn Crowdfunding Operations

## Launch Modes

- Sandbox/non-public testing: supported by local configuration and API access controls.
- Public non-investment crowdfunding: software path implemented, still requires operational review, support readiness and final policy configuration.
- Public investment crowdfunding: disabled pending external legal/product approval.

## Account Closure

Account closure is blocked while a user has active creator campaign obligations or held/refund-pending pledges.

## Operational Risks

- Document storage and external verification provider integration must be finalized before high-scale public launch.
- Public investment campaigns must not be enabled through software-only changes.
