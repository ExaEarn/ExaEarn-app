# ExaEarn Admin Maker-Checker Matrix

| Operation Class | Maker-Checker Requirement |
| --- | --- |
| Real-money product enablement | Required where product policy supports it |
| Treasury exposure limits | Required |
| Provider activation or disabling | Required where provider impacts settlement/fulfillment |
| High-impact fee/pricing policy changes | Required or audited staged change |
| Public product launch gates | Required |
| Reconciliation incident resolution | Required for critical financial mismatches |
| Routine read-only review | Not required |
| Routine support triage | Not required unless it changes funds, identity, or account restrictions |

Maker-checker approval must record actor, approver, reason, before/after values, timestamp, and audit reference.
