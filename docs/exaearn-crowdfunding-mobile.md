# ExaEarn Crowdfunding Mobile

The mobile app now includes a dedicated Crowdfunding screen reached from the dashboard product entry.

## Supported Mobile Flows

- Browse campaigns
- Search campaigns
- View campaign detail
- See funding progress
- Confirm pledge with idempotency key
- View milestones and updates
- Read and post comments/questions
- View contribution history
- Open support for campaign issues

Mobile uses existing authentication and API request infrastructure. It does not create a separate crowdfunding wallet or duplicate the pledge engine.
