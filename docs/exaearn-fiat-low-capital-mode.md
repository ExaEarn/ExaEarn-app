# ExaEarn Fiat Low-Capital Mode

Low-capital mode is enabled by configuration and is designed for development, testing and staged launch preparation.

It allows:

- sandbox provider flows
- virtual-account architecture validation
- webhook security tests
- ledger and reconciliation tests
- admin operational checks

It does not imply:

- live payment provider access
- funded withdrawal reserves
- funded settlement accounts
- legal approval for public fiat operations

Production activation must require provider credentials, banking rails, reserve funding and compliance approval.
