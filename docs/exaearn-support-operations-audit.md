# ExaEarn Support / Disputes / Help Center Audit

## Maturity

Current level: Level 0 to Level 1.

## What Exists

- Web support pages: Support Center, Help Support Center, and Live Support Chat.
- Product-specific dispute models exist in other domains, including P2P and ExaCard.
- Auth errors reference support contact messaging.

## Critical Gaps

- Support Center ticket submission is local UI behavior that shows a success modal and resets state.
- No unified support ticket model, API, attachment storage, assignment, SLA, escalation, knowledge base CMS, or chat backend was identified.
- Product disputes are not unified into a single operations console.

## Required Next Work

1. Build support ticket API, models, policies, attachments, and admin queue.
2. Add ticket lifecycle, SLA, audit logs, and notifications.
3. Integrate product disputes into support operations.
4. Replace local-only success behavior with persisted tickets.
