# ExaEarn Phase 18 Runbooks

## Account Takeover

Create/confirm signals, revoke suspicious sessions, force MFA, hold withdrawals, open ATO case, notify user, monitor recovery.

## API Compromise

Revoke key, preserve safe cancel/reduce operations where possible, create API compromise case, notify owner, inspect request logs.

## Withdrawal Attack

Activate scoped `PAUSE_WITHDRAWALS`, review address risk, coordinate custody/finance review, resolve only after reconciliation.

## Market Manipulation

Create surveillance case, preserve orders/trades evidence, exclude suspicious activity from incentives where policy supports it.

## Admin Compromise

Activate global/security scoped control, revoke sessions, review audit logs, require second security admin review.

## Financial Integrity Alert

Treat Phase 17 critical breaks as security signals, hold sensitive actions, reconcile before recovery.

## Data Exposure

Open SEV incident, preserve timeline, restrict exports, rotate affected secrets where relevant, complete postmortem.
