# ExaEarn ExaSkills Course Lifecycle

Supported states:

- `draft`
- `incomplete`
- `ready_for_review`
- `under_review`
- `needs_changes`
- `approved`
- `scheduled`
- `published`
- `paused`
- `suspended`
- `archived`
- `rejected`

Direct `draft -> published` is blocked. Publishing requires approval and media readiness. State transitions are recorded in course metadata and activity logs.
