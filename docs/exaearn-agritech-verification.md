# ExaEarn AgriTech Farmer and Land Verification

Farmer identity uses the existing ExaEarn identity/KYC foundation. AgriTech separately records operating and land evidence. Evidence requires a private storage reference or an external source reference and begins in `PENDING_REVIEW`.

Authorized reviewers can approve, reject, request information, or flag evidence. Upload presence, coordinates, images, or self-declared metadata never auto-verify a farm. Farmer approval requires verified identity and land evidence. Project approval and public opening require project-level verification, with legal approval for regulated economic types.

Evidence records retain submitter, reviewer, review time, reason, source, and metadata for auditability.
