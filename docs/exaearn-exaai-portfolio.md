# ExaEarn ExaAI Portfolio

## Attribution

ExaAI portfolios and orders are attribution/read models. They are not custody wallets and are not an independent financial source of truth.

Tracked values include:

- Allocated amount
- Available amount
- Reserved amount
- Deployed amount
- Realized PnL
- Unrealized PnL
- Fees
- Strategy/version
- Mode

## Isolation

ExaAI allocation is explicit. It must not consume P2P escrow, staking funds, copy-trading allocations, pending withdrawals or unrelated manual holdings.

## Dashboard Truth

The web dashboard presents real persisted ExaAI orders, sessions, allocations and performance records. It does not display fake or guaranteed returns.
