# ExaEarn Market Maker API

Phase 8 backend supports market-maker account classification and quote records.

Market makers should use future dedicated API credentials with:

- Market-specific permissions.
- Rate limits.
- Fee tier.
- Exposure limits.
- Private execution stream.
- Self-trade prevention.

Phase 8 does not grant market makers admin privileges and does not implement public API-key onboarding. That remains a later developer/API phase.
