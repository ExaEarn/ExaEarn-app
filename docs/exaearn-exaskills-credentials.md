# ExaEarn ExaSkills Credentials

Credentials use `skills_credentials`.

## Issuance

Credential issuance occurs only after:

- valid enrollment
- all lessons complete
- required assessment passed
- course allows credentials

## Verification

Public verification returns safe credential, course and learner display data only.

## Revocation

Admins may revoke credentials with a reason. Records remain; historical credentials are not deleted silently.
