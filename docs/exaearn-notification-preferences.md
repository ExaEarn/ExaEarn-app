# ExaEarn Notification Preferences

Preferences are stored per user and scope in `notification_preferences`.

Supported scopes include transactions, trading, payments, earn, ecosystem, giftcards, exacard, exapay, exaskills, agritech, crowdfunding, rewards, support, security and marketing.

Security and transaction scopes are mandatory. Users may configure optional product and marketing notifications, but opt-outs do not suppress required security, compliance or financial notifications.
