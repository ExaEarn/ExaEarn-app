# ExaEarn Crowdfunding Backer Experience

Backer experience now has a dedicated backend dashboard at `/api/crowdfunding/backer/dashboard`.

## Available Data

- Contribution history
- Total pledge count
- Held-in-escrow count
- Refunded count
- Campaign-linked pledge records

Backers can pledge through the existing canonical escrow flow, post campaign comments/questions, track contribution history, and open support tickets linked to crowdfunding pledge entities.
