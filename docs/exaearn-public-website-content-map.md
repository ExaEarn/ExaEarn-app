# ExaEarn Public Website Content Map

## Homepage

- First viewport: ExaEarn exchange positioning.
- CTAs: Start Trading, View Markets, Connect Wallet.
- API-backed market terminal.
- Public markets strip.
- Institutional, ExaAI, mobile, security, ecosystem and company sections.

## Markets

- `/markets`: searchable public market list from ExaEarn market-data API.
- `/markets/{symbol}`: market details with ticker, order book and recent trades from backend API.

## Trust

- `/security`: account, ledger, market integrity and operational control messaging.
- `/status`: live/reachable endpoint status without unverified uptime claims.
- `/fees`: public pricing endpoint display.

## Legal

- `/legal`
- `/terms`
- `/privacy`
- `/risk`
- `/restricted-jurisdictions`

These pages avoid claiming approvals that require external validation.

## Growth/Partners

- `/developers`: public gateway to developer APIs and sandbox.
- `/listing`: public gateway to token listing workflow.
- `/institutional`: existing institutional access page.
