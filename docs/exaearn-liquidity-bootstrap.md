# ExaEarn Liquidity Bootstrap

Phase 8 supports conservative launch states:

- Internal order book first.
- External reference data available for display and pricing context.
- External executable routing disabled until credentials, funding, reconciliation and failure recovery pass.
- Treasury market-making engine available but reported as not funded until real capital is allocated.
- Withdrawal reserves reported separately from software readiness.

No fake liquidity, fake orders, fake fills or fake production balances are created.
