# ExaEarn Phase 15F Staging Capacity Plan

## Required Staging Scenarios

- 1 listing market moving from approved to pre-launch readiness.
- 1 market with at least 1 funded market-maker subaccount.
- 10 active market-maker bots on the same market.
- OTC market configuration enabled and then disabled through emergency controls.
- Reconciliation run with no critical differences.
- Emergency halt drill with order cancellation and bot pause.

## Current Status

Local focused tests validate software behavior. Larger staging capacity remains environment-dependent and should be run with realistic worker, Redis, database and OMS capacity.
