## SBOM remediation

The SBOM failure originated from the malformed workflow preventing every Anchore step from running, compounded by missing output validation and candidate binding. The workflow now:

- generates separate Syft/Anchore CycloneDX JSON documents for Laravel, realtime, Developer Portal, and Admin;
- disables implicit per-step uploads and creates one deterministic artifact bundle;
- rejects missing, malformed, non-CycloneDX, metadata-free, empty, or component-version-incomplete documents;
- records each SBOM SHA-256, component/dependency counts, CycloneDX version, and `GITHUB_SHA` in `sbom-manifest.json`;
- names the uploaded artifact `exaearn-sboms-${{ github.sha }}` and fails if any required file is missing.

Validator fixtures prove a valid generated document is accepted and hash-bound, while empty and malformed documents fail. Actual four-product SBOM generation remains **external CI verification required** because Syft is not installed locally and Docker/network installation is unavailable. No handwritten dependency inventory was substituted.
