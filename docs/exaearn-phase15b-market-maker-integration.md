# ExaEarn Phase 15B Market Maker Integration

Phase 15B supports market-maker classification through VIP tier definitions, institutional fee profiles, subaccount types and API rate profiles.

Implemented software hooks:

- `MARKET_MAKER` subaccount type
- `market_maker` flag in VIP tier definitions
- institution-specific maker/taker fee profile
- scoped developer API key `rate_profile`

Market-maker operational onboarding remains subject to liquidity, surveillance and exchange operations policy. This phase does not grant permission to fabricate volume or bypass matching, risk, reservations, settlement or ledger controls.
