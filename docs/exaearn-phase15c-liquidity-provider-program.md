# ExaEarn Phase 15C Liquidity Provider Program

The liquidity provider program is institutional-first.

## Requirements

- Approved active institutional account.
- Dedicated active `MARKET_MAKER` subaccount.
- Subaccount-scoped API key using supported Developer Platform permissions.
- Admin-approved market-maker profile.
- Market assignment and liquidity agreement.

## Application States

- `PENDING_TECHNICAL_REVIEW`
- `TECHNICAL_REVIEW`
- `RISK_REVIEW`
- `COMMERCIAL_REVIEW`
- `APPROVED`
- `ACTIVE`
- `PAUSED`
- `SUSPENDED`
- `OFFBOARDED`
- `REJECTED`

## Activation Control

The admin that recommends approval cannot activate the same application. This keeps maker-checker control aligned with Phase 15B institutional operations.
