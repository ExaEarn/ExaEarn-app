# ExaEarn Support Live Chat Settings

Live-chat configuration is stored in `support_live_chat_settings` and managed through admin APIs.

Supported settings:

- `live_chat_enabled`
- `public_chat_enabled`
- `mobile_chat_enabled`
- `web_chat_enabled`
- `operating_hours_enabled`
- `timezone`
- `operating_hours`
- `holiday_dates`
- `default_queue`
- `max_waiting_conversations`
- `max_concurrent_chats_per_agent`
- `offline_ticket_fallback`
- `auto_assignment_enabled`
- `user_wait_timeout`
- `chat_inactivity_timeout`
- `maintenance_mode`
- `maintenance_message`

Production defaults keep public live chat disabled.
